## 使用

运行 `install.ps1` 复制到 Factorio 的 `mods/quality-upcycler_0.1.0`。游戏重新加载模组后，在列表中确认启用 **Quality Upcycler**。

获取测试机器：聊天/控制台输入 `/quality-upcycler-give 5`，不用执行 `/c`。研究“品质插件1”后直接解锁制造，无须额外科技。当前造价为5钢材、10齿轮、5绿板、5红板；品质插件另外插入。已研究品质插件1的旧存档会自动补解锁。

机器使用自制开放式机身和32帧工作动画，实际为炉类：一个输入槽、4个品质插件槽，没有自动吐料口。产物位于原生副产物栏的12个槽中（不是上方保留的旧结果栏），机械臂可正常取出。上方旧结果栏保留用于旧存档安全迁移，其已有物品自动搬到副产物栏。接电后用机械臂进出料，无须选择配方。同一输入槽一次容纳一种物品与品质。

保持或升级的物品全部输出，不在机器内部循环。请在外部分拣，收走目标品质，其余用带子送回。输入优先级由机械臂和外部物流决定。

插满4块普通品质的三级品质插件时，当前概率为（已撤销旧逆矩阵方案）：

| 结果 | 概率 |
| --- | ---: |
| 损毁 | 67.5% |
| 保持 | 20.25% |
| 升一级 | 11.025% |
| 升两级 | 1.1025% |
| 升三级 | 0.11025% |
| 升四级 | 0.01225% |

超过当前已解锁最高品质的结果合并到最高品质；已是最高品质的输入加工后原样输出，不再损毁。未研究史诗、传奇不会提前产出它们。

## 参数和范围

- 基础速度0.5，与回收机相同；每种物品耗时取原版对应回收配方。机器品质与插件减速使用原生计算。工作功率360 kW，待机12 kW，工作合计372 kW；污染4/min。
- 4个槽只接受品质类插件。实际插件等级和品质决定品质率；没有插件时不会升级，仍有75%损耗。无产能插件与插件塔效果。
- 已删除逆矩阵、负概率裁剪和强制99%上限。插件效果相加后限制在0～100%，任意等级/品质的插件都使用同一正向规则。
- 令q为插件合计品质率：损毁=0.75(1-q)，保持=0.25(1-q)^2，升级=q+0.25(1-q)q。升级成功后按每级10%概率继续提升；上限按已解锁品质合并。
- q=10%时，持续回流得到至少优良的平均投入仍是6.5102件；多级目标收益已改变，不再宣称对所有最低目标严格等效原版。此调整优先保证规则直观、所有插件数值有效、所有跳级路径存在。
- 4块普通一级插件实际品质率为4%，4块普通三级为10%，4块传奇三级为25%（本机2.1.23实测）。制造与回收两段统一使用该品质率；当前4槽属于简化设备设定，不宣称保留原双机的8槽投资。
- 自动发现所有实体物品子类型，包括弹药、武器、护甲、装备、修理包、全部科研瓶、载具、带标签/内部库存物品及机器自身；不排除不可堆叠物。隐藏物品、配方参数、仅光标物品和蓝图/选择/规划工具除外。幸存物保留弹药、耐久比例、损伤、装备和库存；内容物维持原品质，外层物品损毁时一起损毁。
- 易腐物保留输入的腐败比例，并计入加工时间；升级不会刷新新鲜度。输出等待期间仍由原生库存处理变质与虫卵触发。脚本在启用加工前记录输入，在完成事件中恢复其年龄；连续加工由原生引擎推进，不额外限制每刻的加工次数。
- 输出没有任一可用位置时不接受新任务。若抽签结果暂时放不下，保留该结果等待取料，不重新抽签。
- 挖掉机器时返还尚未处理完的投入，或已结算但未取出的实际产物，不重抽结果。
- 原生炉类引擎执行实际加工：进度条、当前配方、工作动画、速度、耗电由原生系统驱动。脚本仅在完成后结算升级/损毁并放入副产物栏，不额外叠加原生品质产物。
- Alt模式显示当前原生配方的物品图标。状态文字只显示工作状态，不再显示进度百分比。
- 原生已完成数量是处理件数；生产统计按实际幸存产物及其最终品质记录，易腐物的暂存结果不会重复计产。
- 尚未测试第三方模组修改过的物品、远程拆除链、各种星球/平台以及多人联机。

## 验证

`test.ps1` 只在项目 `runtime/` 目录创建隔离地图。验证加载、全部400000个基准概率权重、五种品质同时放入输出库存、真实机械臂连续投料及取料、无电停机、满输出停机与清空恢复。

`runtime/script-output/upcycler-buffer.json` 和 `upcycler-report.json` 为实际运行记录。少量随机样本只验证行为，不用来估计概率；概率来自完整整数权重枚举。

发布逻辑检查运行 `test-release.ps1`，使用独立 `runtime-release/`，同时运行上述回归与27个发布用例，结果为 `runtime-release/script-output/upcycler-release-report.json`。`test-migration.py` 验证旧档加工中迁移及优化后再次存取。安装和发布只包含 `mod/`，测试助手不随包分发。

### 2026-10-24：切换输入品质卡住修复

复现：输出保留普通和优良铁板，改由机械臂投入优良铁板。输入已经进入机器，但脚本误判输出已满。

本机2.1.23的炉类结果库存中，`can_insert` 对非普通品质返回false，但同一物品的 `insert` 实际成功。容量保护改为带品质参数的 `get_insertable_count`，实际插入仍以 `insert` 返回值为准；无法放入的已结算结果继续保留，不重抽。

新增回归：不清空旧输出，普通铁板切换优良铁板，再切稀有铜板；最后输入传奇铜板验证最高品质直通。测试输出同时保留普通/优良/稀有铁板与稀有/传奇铜板。最高可用品质的原样输出也增加明确状态提示。

### 原生加工、插件与进度改版

已验证：原生进度值与实际加工进度一致；当前配方存在；使用同样插件时速度与真实回收机相同，物品耗时等于对应回收配方。模块测试覆盖无插件、普通一级、普通三级和传奇三级。旧结果栏的物品迁移到副产物栏不丢失。

输出改用副产物库存是为了避免原生结果槽的配方/品质过滤重新引入卡料；测试包含保留普通/优良/稀有铁板输出后继续加工优良铁板，再切换稀有铜板，以及机械臂实际取出副产物。

### 连续跳级与100%品质率修复

已验证0%、4%、8%、10%、25%、99%、100%及超过100%的插件率均产生合法概率；只要q>0，每个尚可到达的更高品质都有非零概率。普通输入、q=100%时结果为优良90%、稀有9%、史诗0.9%、传奇0.1%，无损毁和保持。

隔离测试另外创建了单块+25%的自定义品质插件；插入四块后实际品质率为1，100件输入全部升品、零损毁、零保持。枚举基准40万份权重验证了直接升2/3/4级，实际机械臂测试也观察到普通齿轮直接升史诗。测试插件不随本体安装。

### 3×3 分布式机型的早期解锁

机器直接附加到品质插件1科技的解锁效果，不要求回收科技、外星科研或组装机3。材料暂定5钢材、10齿轮、5电子电路、5高级电路。保留旧独立科技为隐藏兼容记录，不要求新玩家研究。旧存档首次载入会同步已研究品质插件1的配方解锁。

大型升级中心暂未实现，设计定位与候选科技前置见 `../docs/quality_machine_design.md`。
